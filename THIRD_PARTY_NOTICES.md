## Fonts (not shipped in the web bundle)

TTF files under `assets/web/fonts/` report SIL Open Font License 1.1 metadata
in the font tables. **They are not copied into the public website bundle.**
The live site uses system UI fonts plus the original generated lockup PNGs.

If those TTFs are later shipped, include the OFL-1.1 text and font-specific
copyright notices beside them. OFL fonts must not be described as Apache-2.0.

# MVP acceptance

Status words: **WORKING** (runs) · **VALIDATED** (tests/goldens pass) · **NOT YET VALIDATED**.

The MVP succeeds when:

1. Installs on Windows without Internet
2. Launches without Internet
3. Project/hole created locally
4. Convention and units explicit
5. Rapid MD/INC/AZI entry
6. Paste/import
7. Synthetic min-curvature tests pass
8. Selected WinSERVE goldens pass within justified tolerance
9. Independent modern comparison (COMPASS and/or HawkEye) assessed
10. Brett data testable when supplied
11. Current position obvious
12–14. Plan / profile / 3-D useful
15. Targets visible
16. Projections cannot be mistaken for actual
17. Autosave
18. Close/reopen survives
19. CSV/report export
20. Air-gap test
21. Usable at 1366×768
22. No runtime network dependence
23. No LLM in the calculation path
24. README states prototype/evaluation status

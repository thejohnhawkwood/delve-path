## Findings addressed

1. **The product had separate centerline and EOU demonstrations, without a generated collision-correction workflow.** Added an Anti-collision workspace, deterministic crossing-lateral case, endpoint-constrained candidate search, comparison, shared preview layers, complete case import, immutable saved runs and audit replay. The original centerline-only metric retains its original scope.
2. **Centerline refinement did not establish its declared tolerance.** A fixed recursion-depth stop and full-interval deviation bounds were replaced with subinterval sagittae and global distance bounds. A stable half-angle sagitta avoids cancellation for small doglegs. Resolution-budget exhaustion now fails explicitly. Caller-supplied bounds cannot incorrectly prune geometry. An interior exclusion now retains both remaining ranges. Geometry/MD/unit validation rejects inconsistent arcs.
3. **One existing synthetic centerline fixture had incompatible vertical attitudes and horizontal endpoint coordinates.** Replaced that fixture's coordinates/attitudes with an analytically constructed minimum-curvature build. Its exclusion assertions remain; no Oregon, NM, COMPASS or HawkEye golden or tolerance changed.
4. **Covariance MD units were not converted.** MD now follows its declared length unit, and matrix entries follow squared length conversion. Also corrected the TypeScript document helper's ordering that converted `c_*` entries as ordinary lengths.
5. **Confidence text formatted fractional p as a percentage.** 0.95 previously became “1%” in generated labels. Labels now show 95.0%; near-95 probabilities are no longer rounded onto the 95% quantile. Unsupported dimensions and nonfinite MD/scale inputs are rejected. Quantile inversion uses monotone bracketing and NIST reference tests.
6. **Uncertainty previews were wire rings mixed with planar ellipses across every view.** Added real translucent ellipsoid meshes and correctly rotated orthographic outlines; separate 2-D marginal Plan layer. Full covariance cross terms and source descriptions can be entered. No invented survey-tool model or live HTTP result.
7. **3-D proportions omitted added geometry and imposed a minimum axis extent.** Overview now uses data proportions; focused views use explicit displayed ranges. Layer controls are available in the shared chart component.
8. **Centerline results could remain visible after changing their inputs, and unrelated laterals could receive shared-parent exclusions.** Input changes clear results; sibling exclusion requires matching parents.
9. **Desktop file methods were placeholders.** Added native dialog-backed import/export and background native engine dispatch. The default offline CSP and network permissions remain unchanged.
10. **The tooling audit reported five advisories, including a critical development-tool advisory.** Updated Vite to 6.4.3, Vitest to 4.1.11 and the compatible React plugin to 4.7.0. `npm audit` returned zero advisories after the update. These were development-server issues, not evidence of a compromised production bundle. [Vitest advisory](https://github.com/vitest-dev/vitest/security/advisories/GHSA-82fw-gwwq-j7x9), [Vite Windows-path advisory](https://github.com/vitejs/vite/security/advisories/GHSA-fx2h-pf6j-xcff).
11. **CI did not build a Windows installer and its Linux workspace check lacked desktop system prerequisites.** Added Linux prerequisite installation, native/WASM parity evidence and a Windows NSIS build job. These workflow changes have been tested locally where applicable; they have not been pushed or run on GitHub.

## Remaining product boundaries

- This is a conservative geometric planning experiment. Whole-path covariance envelopes are assertions, not propagated survey-tool uncertainty. Actual bit/BHA response, survey quality, joint error correlations, bias models, company rules and operational decision-making require separate work and validation.
- Import accepts explicit offset polylines and coordinate metadata. It is not a geodetic or WITSML importer, and it does not automatically turn arbitrary project surveys into validated offset uncertainty models.
- The older Planning workspace remains a constructor editor, not the complete per-section lock/solve/revision system described in the historical prompt. The Flight Deck's synthetic held-out reveal remains its existing workflow; the new candidate path is not converted into a motor toolface command.
- Geocertainty remains import-only. No live cloud call, token flow, telemetry, field-data upload, remote rig control, commit, push or deployment was performed.
- Saved collision audits carry their own frames and units and are historical records. They are replayed explicitly; they are not silently converted when another workspace's hole unit changes.
- The desktop installer is an unsigned evaluation artifact. Native OS file dialogs still depend on a user's chosen path. Remote CI and field validation are outside the local verification evidence.

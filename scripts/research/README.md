# Research scripts

- `download_sources.ps1` — public PDFs/templates only. No executables.
- `ocr_survey_pages.py` / `scan_pdf_headers.py` — draft OCR; output under gitignored `_ocr/`.
- `build_winserve_fixtures.py` — writes reviewed golden CSVs.

OCR drafts are not golden truth. Fixtures in `research/golden/fixtures/` are the reviewed set.
